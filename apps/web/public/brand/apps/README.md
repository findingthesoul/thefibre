# The launcher tapestry (Matisse cut-out crops)

The launcher popup is ONE poster: 4 tiles × 2 rows. Apps fill the first
cells in order (The Thread, Meet, Members, Pulse, Flow), decorative
crops complete the weave. Drop files here, named:

  the-thread.png  fibre-meet.png  membership.png  fibre-pulse.png  fibre-flow.png
  filler-1.png  filler-2.png  filler-3.png

Square crops, ~600×600. Everything is picked up automatically — a
missing app file falls back to the yellow letters tile; missing fillers
just leave the weave shorter. Swap art by swapping files.
